Data

Default dataset: 32 MIT buildings with sample student sizes and estimated walking distances (mit-campus.js, rebuilt from data/ by tools/build_mit_dataset.py).
JSON: {"buildings":[{"name","type","population?"}], "distances":[[…]]} (matrix in metres, same order as buildings) or "distances":[{"from","to","distance"}].
CSV: columns name,type,population,<one column per building name> forming the distance matrix. Node positions are derived from the distance matrix (MDS). Hover a node for details; drag to rearrange.
