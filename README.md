# Freshman Flu

Local MVP for student illness support at MIT.

## Run it

1. Add optional API keys to `.env`.
2. Run `npm run build`.
3. Run `npm start`.
4. Open `http://localhost:3001`.

For frontend-only development, run `npm run dev` in one terminal and `npm run server` in another.

Demo logins: `Student / demo` and `Volunteer / demo`.

The detailed MVP scope, hardcoded content, and intentionally shortened integrations are in `outputs/MVP_NOTES.md`.
